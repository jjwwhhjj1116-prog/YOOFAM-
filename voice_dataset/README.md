# 나레이션 목소리 데이터셋 (로컬 TTS 재현용)

무협 오디오북 파이프라인의 **나레이션 음성**과 그 **대본 원문**을 짝지은 데이터셋.
로컬에서 같은 목소리를 재현(파인튜닝)하는 용도. 단일 화자, 한국어.

## 규모

| | 1화 | 2화 | 합계 |
|---|---|---|---|
| 클립 | 188개 | 291개 | **479개** |
| 총 길이 | 35분 52초 | 57분 14초 | **1시간 33분** |
| 총 글자 | 16,259자 | 25,684자 | **41,943자** |
| 원본 장면 | 89개 | 128개 | 217개 |

- 형식: **22.05 kHz · 모노 · WAV** · 총 246 MB
- 클립 길이: 거의 전부 **3~15초** (1화 96% / 2화 95%)

## 구성

```
voice_dataset/
├─ wavs/
│   ├─ narr_001_00.wav            ← 1화 (접두어 없음)
│   ├─ ep02_narr_001_00.wav       ← 2화
│   └─ …                            (<화>_narr_<장면번호>_<조각번호>)
├─ metadata.csv                   ← ★ 학습에 쓰는 파일 (LJSpeech 형식)
├─ transcript.txt                 ← 사람이 읽기 쉬운 목록(길이 포함)
├─ scenes/
│   ├─ ep01_narration.tsv         ← 장면 단위 텍스트 (복원본)
│   └─ ep02_narration.tsv         ← 장면 단위 원문 (정본)
└─ README.md
```

### metadata.csv — 클립 단위 라벨 (학습기가 읽는 것)

파이프(`|`) 구분 3열, LJSpeech 그대로:

```
ep02_narr_001_00|화암곡 깊은 협곡을 태우던 불길이…|화암곡 깊은 협곡을 태우던 불길이…
파일명(확장자 없음)|원문|정규화문
```

`wavs/` 와 `metadata.csv` 가 같은 폴더에 있으면 표준 도구가 바로 먹는다.

### scenes/*.tsv — 장면 단위 원문

클립은 3~15초로 잘려 있다. 문장 경계를 다시 잡거나 사람이 검수할 때는 장면 통째
원문이 필요해서 따로 뽑아둔 것. 탭 구분 4열 — `장면 / 초 / 글자 / 나레이션 원문`.
`#` 로 시작하는 머리줄 3개는 건너뛸 것.

- **`ep02_narration.tsv` 는 정본** — 대본에서 그대로 꺼냈다. 초 칼럼도 채워져 있다.
- **`ep01_narration.tsv` 는 복원본** — `오디오/` 폴더가 2화로 덮어써져 대본 정본을
  다시 꺼낼 수 없었다. 클립 텍스트를 장면별로 순서대로 이어 만든 것이라, 클립
  경계에서 공백이 하나 더 들어갈 수 있다(내용은 동일). 초 칼럼은 비어 있다.

학습 라벨로는 `metadata.csv` 를 쓸 것. `scenes/` 는 참고·검수용이다.

## 이 데이터셋의 장점

- **텍스트가 ASR 결과가 아니라 대본 원문이다.** 음성인식 오탈자가 없는 정답 라벨.
  (오디오 분할 시각만 ASR로 잡고, 글자는 대본에서 가져왔다.)
- **단일 화자 · 단일 녹음 조건.** 대사 음성(다른 엔진)이 섞인 장면은 전부 제외했다.
  2화는 199장면 중 순수 나레이션 128장면만 썼다.
- 거의 모든 클립이 **3~15초**라 대부분의 파인튜닝 도구에 그대로 들어간다.

## 쓰는 법

LJSpeech 형식을 그대로 받는 도구들:

- **GPT-SoVITS** — 소량 데이터에 강함. 자체 슬라이서가 있지만 이미 잘려 있으니 바로 사용
- **XTTS v2 파인튜닝** — `metadata.csv` 경로만 지정
- **F5-TTS / Piper** — 전처리 스크립트가 LJSpeech를 기본 지원

공통적으로 `wavs/` 와 `metadata.csv` 가 같은 폴더에 있으면 된다.

## 만드는 법 (다음 화 추가할 때)

저장소 루트에서:

```powershell
# 한 화 덧붙이기 — 기존 클립은 보존된다
.\.venv\Scripts\python.exe _데이터셋_추가.py ep03

# 장면 단위 원문도 갱신
.\.venv\Scripts\python.exe _데이터셋_대본.py ep03
```

`_데이터셋_만들기.py` / `_데이터셋_분할.py` 는 **처음부터 다시 만든다(덮어쓴다).**
`오디오/` 는 화가 바뀌면 같은 번호로 덮어써지므로, 이전 화 클립은 이 폴더에 있는 것이
유일한 사본이다. **이미 쌓인 데이터셋이 있으면 `_데이터셋_추가.py` 를 쓸 것.**

## 주의

- 특정 개인의 음성이다. **본인 목소리 재현 외의 용도로 쓰지 말 것.**
- 무협 낭독체라 억양이 평균적인 대화체와 다르다. 일상 대화 톤을 원하면
  그 톤의 녹음을 따로 섞어야 한다.
- 문장 경계는 ASR 정렬 기반이라 일부 클립의 앞뒤가 몇십 밀리초 잘리거나
  남을 수 있다. 학습에는 지장 없는 수준이지만, 민감한 도구면 무음 트리밍을 한 번 돌리면 된다.
