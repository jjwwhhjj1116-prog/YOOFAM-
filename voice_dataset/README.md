# 나레이션 목소리 데이터셋 (로컬 TTS 재현용)

무협 오디오북 파이프라인의 **나레이션 음성**과 그 **대본 원문**을 짝지은 데이터셋.
로컬에서 같은 목소리를 재현(파인튜닝)하는 용도.

## 규모

| | |
|---|---|
| 클립 | **188개** |
| 총 길이 | **35분 52초** |
| 총 글자 | 16,259자 |
| 클립 길이 | 최소 3.1s / 중앙 12.8s / 최대 16.8s (**96%가 3~15초**) |
| 형식 | 22.05 kHz · 모노 · WAV |
| 화자 | 1명(단일 화자) |
| 언어 | 한국어 |

## 구성

```
voice_dataset/
├─ wavs/
│   ├─ narr_001_00.wav
│   ├─ narr_002_00.wav
│   └─ …                     (narr_<장면번호>_<조각번호>)
├─ metadata.csv              ← LJSpeech 형식
├─ transcript.txt            ← 사람이 읽기 쉬운 목록(길이 포함)
└─ README.md
```

`metadata.csv` 는 파이프(`|`) 구분 3열:

```
narr_001_00|북방 설령산의 겨울은 칼날보다 먼저…|북방 설령산의 겨울은 칼날보다 먼저…
파일명(확장자 없음)|원문|정규화문
```

## 이 데이터셋의 장점

- **텍스트가 ASR 결과가 아니라 대본 원문이다.** 음성인식 오탈자가 없는 정답 라벨.
  (오디오 분할 시각만 ASR로 잡고, 글자는 대본에서 가져왔다.)
- **단일 화자 · 단일 녹음 조건.** 대사 음성(다른 엔진)이 섞인 장면은 전부 제외했다.
- 거의 모든 클립이 **3~15초**라 대부분의 파인튜닝 도구에 그대로 들어간다.

## 쓰는 법

LJSpeech 형식을 그대로 받는 도구들:

- **GPT-SoVITS** — 소량 데이터에 강함. 자체 슬라이서가 있지만 이미 잘려 있으니 바로 사용
- **XTTS v2 파인튜닝** — `metadata.csv` 경로만 지정
- **F5-TTS / Piper** — 전처리 스크립트가 LJSpeech를 기본 지원

공통적으로 `wavs/` 와 `metadata.csv` 가 같은 폴더에 있으면 된다.

## 주의

- 특정 개인의 음성이다. **본인 목소리 재현 외의 용도로 쓰지 말 것.**
- 무협 낭독체라 억양이 평균적인 대화체와 다르다. 일상 대화 톤을 원하면
  그 톤의 녹음을 따로 섞어야 한다.
- 문장 경계는 ASR 정렬 기반이라 일부 클립의 앞뒤가 몇십 밀리초 잘리거나
  남을 수 있다. 학습에는 지장 없는 수준이지만, 민감한 도구면 무음 트리밍을 한 번 돌리면 된다.
